# Mythic Forge

Mythic Forge is a custom Minecraft mod designed for epic medieval fantasy gameplay. It combines a rich fantasy setting with challenging combat, magical elements, and optimized graphics to ensure a smooth and immersive experience. The mod is built for Minecraft 1.20.1 using Forge and Java 17, making it compatible with a wide range of hardware configurations.

## Install

1. Ensure you have Minecraft 1.20.1 installed.
2. Install Forge for Minecraft 1.20.1.
3. Download the Mythic Forge mod from the GitHub repository.
4. Place the downloaded mod file in your Minecraft mods folder.
5. Launch Minecraft and select the Forge profile.
6. Enjoy the epic medieval fantasy experience!

## Use

1. Launch Minecraft and select the Forge profile.
2. Create a new world or load an existing one.
3. Explore the rich fantasy landscapes, including castles, dragons, magic, ruins, and dungeons.
4. Engage in challenging combat with unique boss patterns and rewarding loot.
5. Customize your gameplay with magical abilities and unique items.
6. Enjoy the optimized graphics with Oculus, Embeddium, and Complementary Reimagined shaders for a smooth and visually appealing experience.
